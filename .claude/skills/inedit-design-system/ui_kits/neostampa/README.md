Recreates the **neoStampa Delta** RIP software production manager UI.

## Screens included
1. **Print Queue** — Job list + detail panel with progress, cost, color profile
2. **Printers** — Status grid for all connected printers
3. **Color Profiles** — Profile table with ∆E accuracy ratings

## Design notes
- Dark UI (#1E1E1E base) — print production software convention
- Accent: Pantone 285 C `#0072CE` (neoStampa blue)
- Font: Soho Gothic Pro from `../../fonts/`
- Sidebar with collapsible printer status indicators
- Click sidebar items to switch views; click queue items to see detail
