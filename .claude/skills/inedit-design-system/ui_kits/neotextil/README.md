# neoTextil UI Kit

Recreates the **neoTextil** Adobe Photoshop plugin panel UI.

## Screens included
1. **Repeat tab** — Repeat mode selector, rapport size, generate action
2. **Colorways tab** — Colorway list with swatches, apply action
3. **Export tab** — Format/resolution settings, send to neoStampa

## Design notes
- Dark panel UI matching Photoshop's native dark theme
- Accent: Pantone 485 C `#DA291C` (neoTextil red)
- Left: simulated Photoshop canvas with textile pattern preview
- Right: 260px floating plugin panel — mirrors real PS panel dimensions
- Zoom controls on canvas bar for preview scaling
