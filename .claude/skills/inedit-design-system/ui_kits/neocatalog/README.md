# neoCatalog UI Kit

Recreates the **neoCatalog** workflow and design catalog platform UI.

## Screens included
1. **Catalog grid** — Filterable design grid with color swatches, status badges, search
2. **Design detail** — Overview, colorways grid, history/audit trail tabs

## Design notes
- Light UI (#F6F7F9 base) — web platform convention
- Accent: Pantone 362 C `#509E2F` (neoCatalog green)
- Font: Soho Gothic Pro from `../../fonts/`
- Click any design card to open detail view; click ← Back to return
- Sidebar nav with user profile footer
