# Website UI Kit — Inèdit Software

Recreates the **inedit.com** marketing website UI.

## Screens included
1. **Homepage** — Hero, product overview, feature grid, partner logos, footer
2. **Product page** — neoStampa detail page with features + CTA
3. **Contact / Demo request** — form modal

## Usage
Open `index.html` for the interactive prototype. Click product cards or nav links to navigate between views.

## Notes
- No Figma or codebase was provided; recreated from live website observation
- Font: Soho Gothic Pro (loaded from `../../fonts/`)
- Logo: loaded from `../../assets/`
- Product icon `.ai` files could not be rendered — Lucide icons used as stand-ins
