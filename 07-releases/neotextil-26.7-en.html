Enhancements

nT Colorations

  • Improved performance when using the "Using Only Color Library" option with large gradient color libraries.

nC neoCatalog Panel

  • Relocated the publish colorway button to prevent it from overlapping the variant number, improving usability.
  • Removed the limit on the number of variants displayed, allowing all available variants to be viewed.
  • Newly published variants now appear immediately without requiring the panel to be closed and reopened.

Bug Fixes

nT Colorations

  • Fixed inconsistent interface scaling when multiple color libraries were loaded.

nC neoCatalog Panel

  • Improved activation handling by preventing unexpected errors when an activation has expired.
  • Replaced the non-friendly error message displayed when an authentication token expired with a clearer notification.
