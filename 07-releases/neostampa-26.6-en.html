neoStampa 26.6

This version of neoStampa includes user experience improvements, featuring a live preview for color replacement, greater control over cutting plotter settings, and localization corrections across multiple languages.

What's New

A live preview has been added for Color Replacement on pixel-based files when simulating printing colors, allowing you to verify the result before processing the job.

Enhancements

  • Added the ability to reset cutting plotter advanced settings back to their default values, making it easier to recover a correct configuration after unintended changes.
  • Invalid negative values are now prevented from being entered in the cutting plotter Offset fields, reducing configuration errors.
  • Improved choke unit conversion for more consistent behavior when switching between measurement units.
  • Added missing translations and corrected localization in multiple languages, including Chinese and Italian, improving the overall user experience.
