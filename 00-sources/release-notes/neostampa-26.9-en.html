neoStampa 26.9

We are pleased to announce the release of neoStampa 26.9 in September 2026. This update adds support for a new ink set and includes several enhancements to the DTF drivers, Hot Folders, the Print Server, license activation and DRD.

Enhancements

  • Added support for the CMYKRGBHF ink set.
  • Improved the DTF drivers so that white ink is no longer printed when the white channel is disabled in Properties.
  • Improved Hot Folders so that folders are correctly deleted after ripping when the "Treat subfolder as a single job" option is enabled.
  • Improved the activation window to allow XDat files to be added manually.
  • Improved Print Server port management: the port number now remains stable each time the Print Server is opened, preventing an invalid port from being generated.
  • Improved DRD so that the ink set order shown in the measurement window matches the order of the printed chart.
