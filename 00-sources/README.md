# 00-sources/ — General Source Material

This is the factual ground-truth folder for cross-segment and general-audience work — most importantly the **general newsletter** (sent to the full subscriber list, not a segment), which the orchestrator drafts directly from what's in here, per `CLAUDE.md`.

Rule (see `CLAUDE.md` → "How to Work in This Repo"): before drafting any piece, check `00-sources/` first. Use only data that appears here or in `CLAUDE.md` — never invent beyond those two. Every delivery's closing block states which files from here were used.

## Subfolders

- **`brochures/`** — official product/company brochures (PDF or source doc) used as factual reference for features, positioning, and specs. Not a place for drafts — only finished material received from Product/Marketing.
- **`flyers/`** — official flyers and one-pagers (print or digital) already produced for a product, event, or offer — same rule: finished reference material, not drafts-in-progress.
- **`release-notes/`** — official release notes per product version (e.g. `neostampa-26.6-en.html`). The factual "what's new" record for a release, distinct from `07-releases/`, which holds the *launch campaign plan* built from these notes (timeline, segment messaging, playbook) — not the raw notes themselves.

## What does NOT go here

- Drafts, briefs, or in-progress copy — those stay in each segment's own folder (e.g. `01-existing-customers/drafts/`) or in `07-releases/` for launch planning.
- Anything with `[NEEDS REAL DATA]` placeholders — this folder is for confirmed, finished source material only.
