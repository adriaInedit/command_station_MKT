# Tutorial Video Script: "What Is Print Server? A Beginner's Guide"

**Status:** Draft — ready for review
**Segment:** Customer-facing tutorial (neoStampa), relevant across all three core segments — most directly useful for Existing Customers scaling production and Printer-Brand/Distributor Partners fielding this question from their own customers
**Product:** neoStampa — Print Server component
**Brand color:** neoStampa Blue `#0072CE` (product-specific — this is entirely a neoStampa feature)
**Estimated runtime:** 5–6 minutes
**Goal:** A new or evaluating user understands what Print Server is, when to use it, and what its three main jobs are — queue management, Hot Folder automation, and remote/web-to-print connections — without needing to be a developer. This is a concepts tutorial, not an API deep-dive.
**Scoreboard link:** Supports existing-customer upgrade rate (surfaces a capability underused customers may not know they have) and newsletter → trial click-through (a natural forward-funnel piece for prospects evaluating production automation).

Anyone — or any system — that drops a file into that folder triggers an automatic print, using whatever scheme and layout you've pre-set. No one has to open neoStampa. No one has to click print." **On-screen text:** "Drop a file → it prints. That's it." **VO (cont.):** "This is especially useful if you've got other software on-site — an order system, a design tool, anything that can save a file to a shared folder — that needs to trigger printing without a person in the loop." |

All without a person manually re-entering that order into neoStampa." **On-screen text:** "Web-to-print: your storefront talks directly to the queue." **VO (cont.):** "To make that connection, Print Server generates its own security token — a bit like a password just for that connection.
