# Audio Script (Voiceover Only) — "neoStampa's Printing Job Queue — Every Button, Step by Step"

**Source:** `print-queue-management-script.md` — this is the narration track only, extracted for recording/TTS, with visuals and on-screen text stripped out.
**Estimated runtime:** 7:30–8:00 minutes
**Tone:** calm, confident, professional — not salesy. This is a reference-style walkthrough, so pacing can be slightly brisker and more matter-of-fact than a concept/intro video — the viewer is here to learn a control, not be sold on the idea of one.

---

**[0:00–0:20]**
This is neoStampa's Printing Job Queue — and if you've watched our Print Server overview, you already know what it's for. This time, we're going hands-on: every button on this toolbar, what it does, and when to use it.

**[0:20–0:50]**
Two things to orient on before we start clicking. The job list in the center shows every job you've queued, with its current status. And the toolbar across the top — eighteen buttons — is everything you can do to a job or to the queue itself. Right-clicking any job gives you most of the same options in a context menu, which we'll come back to at the end.

**[0:50–2:30]**
Let's start with the decision you'll make on almost every job: how do you get it from the queue to the printer? Select a job and open Process/Send, and you'll see three options.

Process Only prepares the job — rasterizing it, applying your color and layout settings — but doesn't send anything to the printer yet. Use this when you want the file ready to go, but you're not printing this exact second — maybe the printer's still finishing another job, or you want to review it first.

Process and Send does both in one action — it processes the job and sends it straight to the printer, and lets you set how many copies you want as it goes. This is the one-click option when a job's ready to print right now, no separate steps needed. If you've heard this called "process and send simultaneously" — that's the same thing: processing and sending happen together, back-to-back, instead of you doing Process Only now and Send later.

And Send is for a job that's already been processed — it transmits the prepared file to the printer, and you can also redirect it to a file instead, saving it to a specific location rather than printing it directly. That's useful for archiving a print-ready file, or handing it off to another machine.

**[2:30–2:55]**
Now the toolbar, left to right. Button one, Activate queue — starts the queue processing and printing jobs in order. Button two, Stop queue — halts the whole queue. Use Stop when you need to pause everything, not just one job — a paper change, a maintenance check, anything that affects the printer itself.

**[2:55–4:00]**
Button three, View job information — opens the details for whichever job is selected: settings it was queued with, file info, status history. Button four, Add processed files — lets you bring already-processed PRN or PLT files straight into the queue, skipping the processing step entirely because the work's already done. Button five is Process/Send selected job — the same three-option menu we just walked through, available right here on the toolbar for whichever job you've selected. Button six, Pause selected job — holds just that one job without touching the rest of the queue. Button seven, Stop printing after current copy — if you've queued multiple copies of one job and need to stop, this finishes the copy currently printing instead of cutting it off mid-print, so you're not left with a half-printed piece. And button eight, Cancel job — stops it outright.

**[4:00–4:35]**
Buttons nine through twelve are all about order. Move job to queue head sends it straight to the front — the next thing that'll print. Move job up and move job down nudge it one position at a time. And move job to queue bottom sends it to the back of the line. If a rush job comes in, this is how you reprioritize without cancelling and requeueing anything.

**[4:35–5:20]**
Buttons thirteen through sixteen manage the list itself. Reopen job takes a finished or cancelled job and puts it back to waiting, so you can print it again without setting it up from scratch. Remove selected jobs takes specific jobs out of the list. Delete finished jobs clears out everything marked done, in one click — handy for keeping a busy queue tidy. And delete all jobs — exactly what it sounds like, so use it deliberately. There's no separate undo here, so double-check your selection first.

**[5:20–5:50]**
Button seventeen opens the cost calculation utility — a quick way to check ink consumption and cost estimates for jobs in the queue, without leaving this window. And button eighteen, the last one, opens Queue settings — the configuration panel for how the queue behaves overall. That's worth its own few minutes, so let's open it.

**[5:50–6:40]**
Inside Queue Settings: you can set the temporary folder where the queue stores files while it works, edit the Job ID number if you need your own numbering scheme, and turn on auto-start so the queue begins processing automatically the moment neoStampa launches — useful if this machine runs unattended. You can choose whether the Job ID gets included in the output filename, which helps trace a printed file back to its queue entry later. Retry failed jobs is worth turning on if you're printing over a network connection that occasionally drops — instead of a job just failing, it'll retry automatically. You can also choose to retain processed jobs in the queue instead of clearing them, and set a pause duration between print jobs if your printer or workflow needs a gap between one job finishing and the next one starting.

**[6:40–7:10]**
A few more settings worth knowing, usually reached from the same area. Length Mode applies specifically to Rapport prints — when it's enabled in the RIP with a generated Rapport document, it lets you set the printout length directly. You'll also find Bi-directional Print, Cut Sheet at the End for automatically cutting the material once a job finishes, and Origin Setup, which controls unprinted space at the start of a print — pre-feed lengthwise, and displacement widthwise — so your first mark lands exactly where you expect it.

**[7:10–7:30]**
Last thing — right-click any job, and you'll get a context menu with the same functions we just covered, just laid out differently. If you already know what a button does from the toolbar, the right-click menu should feel familiar — same actions, faster access without moving your cursor up to the toolbar first.

**[7:30–8:00]**
So — the toolbar covers three kinds of control: how a job gets processed and sent, where it sits in line, and what happens to it once it's done. Get comfortable with Process Only, Process and Send, and Send, and the rest of the toolbar is mostly about keeping a busy queue organized. If you want the full written reference, or you're setting up Queue Settings for the first time, check the link below.
