# Inèdit Logos

## Files in This Folder

- **`inedit-fiery-logo-color.png`** — Standard color version. "inēdit" wordmark in cool gray (`#888B8D`) with the "ē" accented in corporate orange (`#FE5000`), paired with the Fiery co-branded mark (red square, white lightning bolt + "fiery" wordmark). Use on light/white backgrounds.
- **`inedit-fiery-logo-white.png`** — Reverse/white version. Same layout, "inēdit" wordmark fully in white (no gray/orange distinction), Fiery mark unchanged. Use on dark backgrounds where the gray version wouldn't have enough contrast.
- **`inedit-logo-color.svg`** — Standalone Inèdit-only wordmark (no Fiery lockup), pulled from inedit.com. Use for product-specific content where the corporate affiliation isn't relevant — see guidance below. `INEDIT_RGB_POSITIVO.png` is referenced in `CLAUDE.md` as an alternate standalone format but hasn't been sourced into this folder yet — `[TODO: source INEDIT_RGB_POSITIVO.png]`.

## Important Context: Inèdit Is Part of Fiery, LLC

Both files show **Inèdit's actual corporate lockup with Fiery** — Inèdit was acquired by Fiery, LLC (announced November 2025) and operates as part of Fiery while retaining its own independent brand and product suite (neoStampa, neoTextil, neoCatalog). This is a real ownership relationship, not an external technology partnership — EFI (Electronics For Imaging), which some older material may reference, was the seller in that transaction and is now a separate OEM partner of Inèdit going forward, not its owner.

**Practical guidance:**
- This co-branded lockup is appropriate for most general Inèdit-branded content (company one-pagers, exhibition booth branding, email footers) since it accurately reflects the company's real structure.
- For narrowly product-specific content where the corporate affiliation isn't the point (e.g. a neoTextil tutorial aimed purely at designers), use the standalone `inedit-logo-color.svg` instead of the full lockup — this is a judgment call based on context, not a strict either/or rule.
- If anything in this repo or elsewhere still describes Fiery as an unrelated print-server partner or implies EFI owns Inèdit, that's outdated and should be corrected.

## Color Notes

The wordmark's gray and orange in the color version match the official corporate colors already documented in `../typography-colors/corporate-colors.md` (`#888B8D` and `#FE5000`) — confirms those values are correct and actively used in real assets, not just documented values.
