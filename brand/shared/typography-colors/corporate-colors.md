# Inèdit Corporate Colors (General Brand — Official)

Source: Inèdit Manual de marca (brand manual), p.9 — "Colores corporativos." This is the official general Inèdit color reference, distinct from the product-specific colors in `product-colors.md` in this same folder.

> [!IMPORTANT]
> Use this for anything representing **Inèdit as a company** (the company logo, general one-pagers, exhibition booth branding that isn't product-specific, the email footer). Use `product-colors.md` instead when the content is specifically about neoStampa, neoTextil, or neoCatalog.

## The Two Corporate Colors

### Orange — PANTONE 021 C
- CMYK: 0/65/100/0
- RGB: 254/80/0
- HTML: `#FE5000`

### Cool Gray — PANTONE Cool Gray 8 C
- CMYK: 23/16/13/46
- RGB: 136/139/141
- HTML: `#888B8D`

The gray also has defined tint percentages for use as a supporting/secondary tone: 100%, 80%, 60%, 40%, and 20% — useful for backgrounds, secondary text, or subtle UI elements without introducing a new color.

## Which Format to Use, When (official usage rules)

| Format | Use for |
|---|---|
| **Pantone** | Own print productions produced in offset. |
| **CMYK** | Print produced by others (e.g. magazine ads); also for own digital print productions. |
| **RGB** | Images created using the corporate colors for screen; also for Office programs. |
| **HTML** | Text and corporate-color elements that aren't images, on digital platforms. |

For this repo's day-to-day work (digital content — emails, social, web, Claude Design briefs), **HTML (`#FE5000` / `#888B8D`) is almost always the right choice** — Pantone and CMYK mainly matter if/when something genuinely goes to offset print (e.g. printed exhibition materials).

## Note on Existing Repo Usage

The orange (`#FE5000`) was already used as an accent color in this repo's existing templates (the neoStampa email, the 90-day plan and daily cadence Word docs) — that usage is correct, since it's the genuine corporate orange, not a guess. The repo has not yet made consistent use of the cool gray as a secondary corporate tone; consider it for body text, secondary UI elements, or backgrounds in future templates rather than defaulting to a different gray.
